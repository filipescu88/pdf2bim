• W, A, S, D / Strzałki — chodzenie / lot (Shift = szybciej)
• Mysz (Przeciągnij LPM) — rozglądanie 360°
• Klik LPM na drzwi lub [O] — otwieranie/zamykanie drzwi
• [F] — przełącz Spacer (z kolizjami i schodami) / Lot (Q/E góra/dół)
• PPM / [M] — postaw punkt Mazaka Laserowego QA
• ENTER VR (na dole) — pełny tryb gogli Meta Quest 3 WebXR
